# Pokémon Pokopia H5 攻略网站项目

## 游戏概览

**Pokémon Pokopia** — 2026年3月5日发售，NS2 平台独占。

- **开发商**：Game Freak + Omega Force（光荣特库摩）
- **发行商**：Nintendo / The Pokémon Company
- **类型**：生活模拟（Life Simulation）
- **引擎**：Katana Engine
- **模式**：单人 / 多人

### 核心玩法

玩家操控一只 **百变怪（Ditto）** 伪装成人类，通过建造栖息地来吸引不同宝可梦。游戏包含：

- **制作 & 建造** — 收集材料、制作道具、建造设施
- **栖息地系统** — 每种宝可梦需要特定环境条件才会出现（如咕咕需要黑暗环境）
- **宝可梦互动** — 宝可梦可以教百变怪新技能，用于与环境互动（创建灌木、浇水、砍伐、碎石等）
- **昼夜周期** — 与现实时间联动
- **多生物群落（Biomes）** — 不同区域有不同的生态环境

## 初步规划

### 网站模块

1. **📖 宝可梦图鉴**
   - 搜索 / 筛选功能
   - 点击查看详情（属性、技能、喜好、栖息地需求）

2. **🏕️ 栖息地指南**
   - 每种宝可梦需要什么环境条件才会出现
   - 栖息地类型一览（Cafe Space、Light-Up Stage、Pikachu Space 等）

3. **🔨 制作手册**
   - 配方查询
   - 材料需求和获取方式

4. **🗺️ 生物群落地图**
   - 各区域有什么宝可梦
   - 区域特征和资源分布

5. **💡 攻略提示**
   - 卡关常见问题
   - 进度推进建议

### 技术栈（初步）

- **前端**：HTML5 + CSS3 + Vanilla JS（或 Vue/React，视复杂度决定）
- **数据格式**：JSON（方便维护和更新）
- **部署**：纯静态页面，可本地打开或部署到任意静态托管
