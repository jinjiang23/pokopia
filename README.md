# Pokémon Pokopia H5 攻略网站项目

## Wiki 核心数据

根据已发现的公开数据源，游戏核心数据包括：

| 数据类型 | 说明 |
|---------|------|
| 🐾 宝可梦图鉴 | 每只的属性、技能、喜好、出现条件 |
| 🏕️ 栖息地系统 | 不同宝可梦需要的特定环境条件 |
| 🔨 制作配方 | 道具 & 设施的制作方式和材料需求 |
| 🌍 生物群落 | 各区域的生态特征和可遇宝可梦 |
| 🌙 昼夜周期 | 现实时间联动机制，影响宝可梦出现 |
| 🪑 家具 & 道具 | 装饰物品和功能道具列表 |
| 🌾 作物种植 | 种植系统相关数据 |

### 主要数据源

- **Pokémon Pokopia Wiki (Fandom)** — https://pokemon-pokopia.fandom.com/
  - 社区百科，覆盖宝可梦、道具、家具等
- **Game8 攻略站** — https://game8.co/games/Pokemon-Pokopia
  - 栖息地建造、作物种植、材料收集、任务攻略
- **Wikipedia** — https://en.wikipedia.org/wiki/Pokopia
  - 游戏基础信息和背景

## 网站模块

1. **📖 宝可梦图鉴**
   - 搜索 / 筛选功能
   - 点击查看详情（属性、技能、喜好、栖息地需求）

2. **🏕️ 栖息地指南**
   - 每种宝可梦需要什么环境条件才会出现
   - 栖息地类型一览（Cafe Space、Light-Up Stage、Pikachu Space 等）

3. **🔨 制作手册**
   - 配方查询
   - 材料需求和获取方式

4. **🗺️ 生物群落地图**
   - 各区域有什么宝可梦
   - 区域特征和资源分布

5. **💡 攻略提示**
   - 卡关常见问题
   - 进度推进建议
